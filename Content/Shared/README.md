# Content/Shared

여러 JUN 툴이 **함께 쓰는 에셋**을 둔다. 마운트 경로는 `/JUNTools/Shared/`.

- 한 툴만 쓰는 에셋은 여기가 아니라 `Content/A00NNN_<name>/` (파이썬 툴 폴더와 같은 이름)에 둔다.
- 지원 하한이 UE 5.4 라서 에셋은 **5.4 에디터에서 만들고 저장**한다. 5.5 이상에서 저장하면 5.4 에서 못 연다.
- 이 파일은 빈 폴더를 git 에 남기기 위한 것이기도 하다(git 은 빈 폴더를 추적하지 않는다).
  언리얼은 `.md` 파일을 에셋으로 읽지 않으므로 콘텐츠 브라우저에는 보이지 않는다.
